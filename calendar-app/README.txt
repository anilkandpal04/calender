マイカレンダー (My Calendar) - How to run
1. Install XAMPP (or any PHP server). Or with PHP installed, run in this folder:
      php -S localhost:8000
   then open http://localhost:8000
2. XAMPP: copy this folder into htdocs, open http://localhost/calendar-app/
3. The data/ folder must be writable (events are saved in data/events.json).

Pages:  index.php (calendar)  /  add.php (予約登録)  /  list.php (予約一覧)
